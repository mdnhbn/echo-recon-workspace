## কী অবস্থা

Mac-এ চালানোর ব্যবস্থা 6.7.0-এ GitHub-এ প্রকাশ করা হয়েছে। এরপর পুরো প্রজেক্টের code, installer, tool চালানোর নিয়ম, report, privacy, update ব্যবস্থা এবং documentation পরীক্ষা করে 6.7.1-এর সংশোধন প্রস্তুত করা হয়েছে। পরীক্ষার শুরুতে মূল code ছিল commit `584b35df7b83fe60b022981e68d902ac028442f1`।

এটি প্রজেক্টের ভেতরের engineering audit। এর অর্থ code ও নির্দিষ্ট ব্যবহার পরীক্ষা করা হয়েছে; এর অর্থ সব operating system বা সব website-এ সব tool সবসময় ঠিক কাজ করবে—এমন নিশ্চয়তা নয়। কোনো বাইরের website scan করা হয়নি। আপনার পুরোনো history/report মুছে ফেলা হয়নি।

- নয়টি tool-এর সঙ্গে যোগাযোগ: DNSRecon, Subfinder, HTTPX, Nmap, theHarvester, Photon, Arjun, Nuclei ও Nikto।
- Domain/URL গ্রহণ, অনুমোদিত host নির্ধারণ, scan শুরু/বন্ধ, progress এবং ভুলের ফল দেখানো।
- Browser interface, local server, history, HTML/JSON report ও secret আড়াল করার ব্যবস্থা।
- Windows, Linux ও Mac installer, download যাচাই, আলাদা tool folder এবং update-এর নিয়ম।
- GitHub পরীক্ষা, Kali-এর signed APT feed, README এবং contribution-এর নির্দেশনা।

## যেসব সীমাবদ্ধতা মনে রাখতে হবে

1. **পুরোনো APT workflow আবার চালাবেন না।** নতুন guard 6.7.1 থেকে আছে। 6.7.0 বা তার আগের workflow আবার চালালে তার পুরোনো code-ই চলে; সেটি নতুন feed বদলে দিতে পারে। এমন হলে সর্বশেষ matching release workflow আবার প্রকাশ করতে হবে। ইতিহাসের tag বা secret এই audit-এ বদলানো হয়নি।
2. **Mac-এর জন্য Homebrew আগে লাগবে।** Apple Silicon-এ native Terminal ব্যবহার করতে হবে। Intel/Homebrew package পাওয়া upstream support-এর ওপর নির্ভর করে। এটি signed `.app` installer নয়; Terminal থেকে local browser interface চলে।
3. **সবকিছুর একেবারে নির্দিষ্ট version lock নেই।** Dashboard hash lock আছে। কিছু tool-এর Python dependency, Homebrew package ও Nuclei templates upstream-এ বদলায়। ভবিষ্যতে প্রতি platform-এর পূর্ণ dependency lock উন্নত করা যেতে পারে।
4. **সময় limit ফিরিয়ে আনা হয়নি।** Tool নিজে শেষ না হলে Stop দিন। Disk/network ব্যবহার খেয়াল করুন; crawler-এর সব scratch file-এ আকারের সীমা নেই। Local tool-check আটকালেও নিজের কোনো deadline নেই।
5. **Scope যাচাই network firewall নয়।** Third-party tool আবার DNS resolve করতে বা অন্য link/provider-এ যেতে পারে। POSIX process group ইচ্ছা করে নতুন session-এ পালানো program আটকানোর পূর্ণ sandbox নয়।
6. **Report share করার আগে পড়ুন।** নতুন redaction পুরোনো report বা raw crawl file পরিষ্কার করে না। অচেনা secret format থেকে যেতে পারে।
7. **একটি tool ready মানে website নিরাপদ নয়।** Ready হলো local program/help/templates-এর পরীক্ষা। আসল finding মানুষকে যাচাই করতে হবে। একটি physical Mac-এ graphical review এবং নতুন Kali-তে পুরো APT install পরীক্ষা ভবিষ্যৎ acceptance কাজ হিসেবে উপকারী। Android support এই কাজের অংশ নয়।

## Mac-এ কীভাবে চালাবেন

Homebrew তার [official নির্দেশনা](https://brew.sh/) অনুযায়ী আগে install করে নিন। তারপর সাধারণ user হিসেবে Terminal-এ এক লাইন করে দিন:

```bash
brew install python@3.12 git
mkdir -p ~/Tools
cd ~/Tools
git clone https://github.com/mdnhbn/echo-recon-workspace.git
cd echo-recon-workspace
bash install.sh
bash run.sh
```

Terminal খোলা রাখুন। Browser না খুললে একই Mac-এ `http://127.0.0.1:8001` খুলুন। Interface-এর **Check installed tools** দিয়ে অবস্থা দেখুন; **Setup all tools** দিয়ে প্রয়োজন হলে আবার চেষ্টা করুন। এই setup নিজে কোনো website scan শুরু করে না। সামনে `sudo` বসাবেন না।

Mac-এ আগে install করা থাকলে app বন্ধ করে `data/`-এর private backup রাখুন, project folder-এ `git pull --ff-only`, তারপর `bash install.sh` ও `bash run.sh` দিন। Mac-এর জন্য `apt upgrade` নয়। [সম্পূর্ণ বাংলা Mac guide](MACOS.bn.md)-এ বিস্তারিত আছে।

Kali-তে signed APT package ব্যবহার করলে নতুন release সফলভাবে প্রকাশের পরে `sudo apt update && sudo apt upgrade` প্রযোজ্য। Windows source installation-এর update নিয়ম [WINDOWS.md](WINDOWS.md)-এ আছে। GitHub update হওয়া মানে সব পুরোনো local copy নিজে থেকে বদলে যাওয়া নয়।

Audit চলাকালে মূল Windows project folder-এ file লেখা আটকে যাওয়ায় আলাদা Git copy-তে কাজ ও পরীক্ষা করা হয়েছে। মূল folder এবং আপনার private data অক্ষত রাখা হয়েছে; প্রকাশিত GitHub repository থেকে সংশোধন পাওয়া যাবে।
