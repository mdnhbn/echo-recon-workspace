রিকন Echo Recon

Scope first. Evidence always. / প্রমাণসহ পরীক্ষা।

{% if native_windows %}
Windows native: automatic backend setup and scoped assessments.

First startup prepares missing tools together. Nmap uses its official Windows installer and TCP connect scans (-sT -Pn). Nikto setup needs Perl available on PATH; the installer will show how to add it if missing.
প্রথমবার চালালে প্রয়োজনীয় tool-গুলো একসঙ্গে সেটআপ হবে। Nmap-এর official installer-এ প্রয়োজনীয় confirmation দিন। Nikto চালাতে Perl লাগবে; না থাকলে installer নির্দেশনা দেখাবে।

01

Assessment / পরীক্ষার সেটআপ

Write only the hostname, e.g. example.com. Replace this with your own permitted domain; no https://, path or port.
নিজের অনুমোদিত domain লিখুন; পুরো website link নয়।

Include the primary domain; add only its permitted subdomains, one per line (maximum 5 total). Discovered hosts are not added automatically.
মূল domain-টিও লিখুন; মোট পাঁচটি পর্যন্ত। নতুন পাওয়া subdomain নিজে থেকে পরীক্ষা হবে না।

Select checks / পরীক্ষার ধাপ বেছে নিন

Select both Nuclei and Nikto to run Nikto only if Nuclei is missing or fails. Select Nikto alone for a standalone server check.
Nuclei ও Nikto দুটো বাছলে Nuclei না থাকলে বা ব্যর্থ হলে তবেই Nikto চলবে। শুধু Nikto বাছলে এটি আলাদা scan হিসেবে চলবে। Nikto-র check সীমিত রাখা হয়েছে।

Enter a whole number from 1 to 5. Lower rate reduces traffic for tools that support it; default: 2/second.
১–৫-এর পূর্ণসংখ্যা দিন; সব tool মিলিয়ে মোট গতি নয়।

Enter 10–180 seconds; default: 120. This is a per-tool/host limit, not the whole assessment time.
১০–১৮০ সেকেন্ড দিন; default ১২০।

Only assess authorized hosts.
শুধু অনুমোদিত host পরীক্ষা করুন।
