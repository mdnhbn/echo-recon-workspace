1. Start here / শুরু করবেন যেভাবে

Use your normal Kali user. Keep the dashboard terminal open. This page organizes eight separate tools and saves their evidence; opening it does not start a scan.
সাধারণ Kali user থেকে চালান। শুধু পেজ খোলায় পরীক্ষা শুরু হয় না।

  1. Check installed tools → set up anything missing.
  2. Enter your permitted domain and exact host list.
  3. Select checks, rate and time limit; read and tick both confirmations.
  4. Start assessment → watch progress → open the report.

2. Check and install / টুলের সেটআপ

Check installed tools runs local help/identity checks. ready means these checks passed; missing means not found on PATH; unverified means the found program/version needs attention.

Setup all tools opens a visible Kali terminal. The fixed installer skips verified working tools and prepares missing ones in system-managed packages or separate user folders. If needed, type your sudo password in that terminal; characters normally stay hidden. Close the finished terminal, then check tools again. Internet and enough free disk space are required.

আগে থেকে ঠিক থাকা tool আবার ইনস্টল করে না। কোনো command ব্যর্থ হলে terminal-এর error দেখুন; সফল হয়েছে ধরে নেবেন না। নিজের wrapper-এর সঙ্গে নামের সংঘর্ষ হলে পুরোনো ফাইল overwrite করবে না।

Native Windows uses the dashboard and saved reports; install assessment tools inside Kali WSL2. For manual/headless setup, first finish or stop any assessment. Open your own Kali terminal in this repository and run .venv/bin/python setup_tools.py --install. Preview the fixed plan with .venv/bin/python setup_tools.py --plan.

3. Fill the form / কোন ঘরে কী লিখবেন

Primary domain / মূল ডোমেইন
Write the hostname only, such as example.com. Replace it with your own permitted domain. Do not include https://, a path, port, IP address or wildcard.
Exact authorized hosts / অনুমোদিত host
Put the primary domain here too. One hostname per line, maximum five total; additional hosts must be subdomains of the primary domain. Example structure: 
example.com
app.example.com
এগুলো উদাহরণ—নিজের অনুমোদিত domain দিয়ে বদলান। নতুন পাওয়া subdomain নিজে থেকে এই তালিকায় যোগ হবে না।
Select checks / পরীক্ষার ধাপ
Select only the steps you need. The first three are selected initially. Photon/Arjun need HTTPX selected in the same run and a confirmed live in-scope host; their current adapters use HTTPS.
Confirmations / নিচের দুই checkbox
Confirm you own the hosts or have explicit permission, and understand that external tools have their own network behavior. Then press Start assessment.

4. Rate ceiling / গতিসীমা কেন?

Think of sending letters slowly instead of sending a pile at once. Lower rates reduce bursts and load. The default is 2/second; available choices are 1, 2 and 5. A cautious first run can use 1.

HTTPX, Arjun and Nuclei receive their rate-limit settings. Nmap uses a packet-rate ceiling. Photon uses a delay (2/second → 0.5-second delay). DNSRecon, Subfinder and theHarvester do not receive this rate setting. It is not a guaranteed global request/packet budget, and speed does not determine whether you have permission.

গতিসীমা কম রাখলে server-এর ওপর চাপ কমতে পারে, তবে শেষ হতে বেশি সময় লাগতে পারে। সব tool একভাবে গতি নিয়ন্ত্রণ করে না।

5. Time per tool / host / ১২০ সেকেন্ড কী?

120 seconds = a two-minute process budget for one tool's attempt on one host. If it finishes in 8 seconds, the next attempt starts then; it does not wait for the full 120. If it is still running at the limit, the process is stopped and that attempt is marked timeout; cleanup can add a little time. Earlier output may be kept, but the result is incomplete.

This prevents a slow or stuck tool holding the queue indefinitely. A longer allowance may collect more evidence but also takes longer. Choose 30/60/120/180 seconds. Lower rate plus a short limit can leave a stage unfinished; inspect the report before changing the settings.

এটি পুরো job-এর মোট সময় নয়। আটটি tool এবং একটি host হলে শুধু process-এর সময়সীমাগুলো যোগ করে প্রায় ১৬ মিনিট পর্যন্ত হতে পারে। পাঁচটি host-এ সব ধাপ চললে বর্তমান pipeline-এ সর্বোচ্চ ২৮টি attempt: ১২০ সেকেন্ডে প্রায় ৫৬ মিনিট process allowance। Help/DNS/provider/startup/cleanup-এর বাড়তি সময় থাকতে পারে; এটি wall-clock deadline নয়। বাস্তবে দ্রুত শেষ হতে পারে বা কিছু ধাপ skipped হতে পারে।

7. Progress and reports / ফল কীভাবে পড়বেন?

Stop requests cancellation. done means the command exited successfully. timeout/error/missing/unverified/skipped/output_limit means review that phase's explanation. partial means the assessment has incomplete phases; interrupted means an unfinished saved job was recovered when the server restarted.

View report opens saved evidence; expand a phase to see output, errors and host attempts. HTML saves a readable report; JSON saves structured data. Saved history reopens an earlier assessment without starting a new scan.

কোনো finding না পাওয়া মানে সাইট নিরাপদ—এমন সিদ্ধান্ত নয়। Findings আগে হাতে যাচাই করুন। Share করার আগে report-এ sensitive তথ্য আছে কি না দেখুন।

8. Change interface / interface বদলানো

The header's Light layout / Dark layout button switches between the two layouts in one click and remembers your choice when browser storage is available. Form values and results stay in place. Matrix rain remains in both; reduced-motion preferences disable animation.
