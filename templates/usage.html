1. Start here / শুরু করবেন যেভাবে

Use your normal user account. Keep the dashboard terminal open. This page organizes nine separate tools and saves their evidence; opening it does not start a scan.
সাধারণ user থেকে চালান। শুধু পেজ খোলায় পরীক্ষা শুরু হয় না।

  1. Check installed tools → set up anything missing.
  2. Enter your permitted domain or URL and exact host list.
  3. Select checks and rate; read and tick both confirmations.
  4. Start assessment → watch elapsed time and progress → open the report.

2. Check and install / টুলের সেটআপ

Check installed tools runs local help/identity checks. ready means these checks passed; missing means not found on PATH; unverified means the found program/version needs attention.

{% if native_windows %}Setup all tools starts the native Windows installer and shows progress in this page. The seven original compatible tools install into separate user folders; Nikto source also installs when Strawberry Perl is already on PATH. Nmap requires its official Windows installer; Perl itself is a separate prerequisite. Complete Nmap's license/administrator prompts yourself, then check tools again. Fixed automatic pins require Python 3.12 x64. Windows assessments use the same scope and report controls; Nmap uses TCP connect (-sT -Pn). Local help checks verify installation, not an assessment result.{% else %}Setup all tools opens a visible Linux terminal. The fixed installer skips verified working tools and prepares missing ones in system-managed packages or separate user folders. If needed, type your sudo password in that terminal; characters normally stay hidden. Close the finished terminal, then check tools again. Internet and enough free disk space are required.{% endif %}

আগে থেকে ঠিক থাকা tool আবার ইনস্টল করে না। কোনো command ব্যর্থ হলে terminal-এর error দেখুন; সফল হয়েছে ধরে নেবেন না। নিজের wrapper-এর সঙ্গে নামের সংঘর্ষ হলে পুরোনো ফাইল overwrite করবে না।

Windows native, supported Linux distributions, WSL Linux and VirtualBox Kali use the same scoped dashboard. First startup checks and prepares missing tools; use Setup all tools to retry. To skip startup setup, add --no-tool-setup (PowerShell: -NoToolSetup). For a read-only native Windows plan use .venv\Scripts\python.exe setup_tools_windows.py --plan. On Linux/WSL, run .venv/bin/python setup_tools.py --install from your terminal after stopping assessments; --plan previews it without changes.

3. Fill the form / কোন ঘরে কী লিখবেন

Website URL or domain / Website URL অথবা domain
Enter a permitted domain such as example.com or a public http(s) page URL such as https://example.com:8443/help. HTTPX, Nuclei, Photon and Arjun receive the page path and supplied port for the primary host; domain-level checks use the hostname. Query strings and fragments are omitted. Credentials, IP addresses and wildcards are rejected. A username is not a supported target.
Additional authorized hosts / বাড়তি অনুমোদিত host
Leave this blank to use only the hostname extracted from the target above. Or list up to four permitted subdomains, one per line; the primary host is included automatically, for up to five total. Hostnames or public http(s) URLs are accepted; only their host is used for authorization. Example structure: 
app.example.com
api.example.com
এগুলো উদাহরণ—নিজের অনুমোদিত domain দিয়ে বদলান। নতুন পাওয়া subdomain নিজে থেকে এই তালিকায় যোগ হবে না।
Select checks / পরীক্ষার ধাপ
Select only the steps you need. The first three are selected initially. Photon/Arjun need HTTPX selected in the same run and a confirmed live in-scope host; they use the supplied URL scheme and do not retry another scheme automatically. Select both Nuclei and Nikto for fallback: Nikto runs only if Nuclei does not complete. If Nuclei completes with no matches, Nikto is skipped. Select Nikto alone to run it by itself.
Confirmations / নিচের দুই checkbox
Confirm you own the hosts or have explicit permission, and understand that external tools have their own network behavior. Then press Start assessment.

4. Rate ceiling / গতিসীমা কেন?

Enter a whole number from 1 to 5 requests/second; the default is 2. Lower rates reduce bursts and load. A cautious first run can use 1.

HTTPX, Arjun and Nuclei receive their rate-limit settings. Nmap uses a packet-rate ceiling. Photon and Nikto use a delay (2/second → 0.5-second delay). Nikto's pause is between tests, not a strict global request meter. DNSRecon, Subfinder and theHarvester do not receive this rate setting. It is not a guaranteed global request/packet budget, and speed does not determine whether you have permission.

সেকেন্ডে ১–৫-এর মধ্যে পূর্ণসংখ্যা লিখুন; default ২। গতিসীমা কম রাখলে server-এর ওপর চাপ কমতে পারে, তবে শেষ হতে বেশি সময় লাগতে পারে। সব tool একভাবে গতি নিয়ন্ত্রণ করে না।

5. Timing and progress / চলার সময় ও অগ্রগতি

Echo Recon applies no per-tool or whole-assessment time limit, including to local tool identity checks. Each tool runs until it exits, reaches the output cap, or you press Stop. A tool can still exit with its own error. Only one assessment runs at a time.

The overall bar counts resolved phases; each phase bar counts completed host attempts. The dashboard shows elapsed time and an estimated remaining time after completed work is available. Per-tool estimates use completed host attempts; the overall estimate uses completed phases. Both are rough because tools and targets differ. Many tools do not report a real percent within one host, so the dashboard marks that progress as unavailable instead of guessing.

Dashboard থেকে আলাদা tool বা পুরো scan-এর সময় বেঁধে দেওয়া নেই। Tool নিজে শেষ হবে অথবা Stop চাপলে থামবে। কোনো tool বা provider নিজের network/request error দিতে পারে—সেটি dashboard timer নয়। একসঙ্গে একটি assessment চলে এবং output-এর সীমা থাকে।

Overall bar-এ শেষ হওয়া phase, আর প্রতিটি tool-এর bar-এ শেষ হওয়া host attempt গোনা হয়। Elapsed time সবসময় দেখা যায়; একটি phase শেষ হলে বাকি সময়ের আনুমানিক হিসাব দেখায়। Tool-গুলো host-এর ভেতরের প্রকৃত percentage না দিলে dashboard তা বানিয়ে দেখায় না।

7. Progress and reports / ফল কীভাবে পড়বেন?

Stop requests cancellation. done means the command exited successfully. error/missing/unverified/skipped/output_limit means review that phase's explanation. Older saved reports may contain timeout. partial means the assessment has incomplete phases; interrupted means an unfinished saved job was recovered when the server restarted.

View report opens saved evidence; expand a phase to see output, errors and host attempts. HTML saves a readable report; JSON saves structured data. Saved history reopens an earlier assessment without starting a new scan.

কোনো finding না পাওয়া মানে সাইট নিরাপদ—এমন সিদ্ধান্ত নয়। Findings আগে হাতে যাচাই করুন। Share করার আগে report-এ sensitive তথ্য আছে কি না দেখুন।

8. Change interface / interface বদলানো

The header's Light layout / Dark layout button switches between the two layouts in one click and remembers your choice when browser storage is available. Form values and results stay in place. Both layouts use a static background with motion effects removed to reduce resource use.
